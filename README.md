# ZenMind

An AI-powered product experiment built around conversational and intelligent user experiences.

## Engineering Highlights
- React 19 application architecture
- TypeScript-first development
- Google Gemini integration through the GenAI SDK
- Lightweight Vite build pipeline
- Purpose-built interface for AI-native interaction

## Tech Stack
React 19 · TypeScript · Vite · Google GenAI · Lucide React

## Development
```bash
npm install
npm run dev
```

Configure the required Gemini API environment variable locally before running the project.
